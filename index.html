WHY CALYPSO

A distro with
an identity.

Calypso is about cohesion rather than noise: one desktop at the center, a clear optional window-manager path, and a visual system that follows the whole project from the boot menu to the desktop.

01 / DESKTOP

KDE, first.

KDE Plasma is the main Calypso desktop. The surrounding defaults, branding, and wallpapers are designed around it.

02 / WINDOW MANAGEMENT

Hyprland, optional.

Hyprland is an optional but recommended window manager for people who want a more keyboard-driven, tiling-oriented workflow.

03 / INSTALLATION

Calamares, properly.

The project now uses Calamares for a real graphical install flow, including partitioning, accounts, system setup, and bootloader installation.

04 / AESTHETIC

Emerald & obsidian.

Crystalline geometry, dark surfaces, mint highlights, and restrained glow create the visual language behind Calypso.

05 / ARCH

Start close to upstream.

Calypso keeps the flexibility of an Arch-based foundation while assembling its own desktop presentation and installer experience.

06 / OPEN SOURCE

Everything is inspectable.

The ISO profile, artwork, website, optional Hyprland configuration, and build work live together in one public project.

INSTALLER

From boot
to desktop.

Calypso now uses Calamares for installation. The graphical flow handles disk setup, user creation, locale and keyboard configuration, system installation, display-manager configuration, and systemd-boot setup.

UNDER THE HOOD

The pieces fit
together.

The project is intentionally split into layers so the ISO can evolve without the website, branding, and optional desktop configuration drifting apart.

01 / ISO

The live image.

The Archiso profile assembles the live KDE Plasma environment, Calamares, Hyprland packages, artwork, boot entries, and system defaults.

02 / DESKTOP

The main surface.

KDE Plasma is the center of Calypso. The distribution keeps its own visual identity while retaining Plasma's broad configuration surface.

03 / HYPRLAND

The optional path.

Hyprland is an optional, recommended window manager for users who prefer tiling, keyboard-driven interaction, and deeper customization.

One repository, many layers.

Website, documentation, ISO files, artwork, and the optional Hyprland configuration are developed together so the public project remains understandable.
