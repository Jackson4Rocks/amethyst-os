01 / THE SYSTEM

Small stack.
Big atmosphere.

Calypso is designed as a coherent desktop rather than a pile of unrelated tweaks: a clean base, focused defaults, and a visual language that carries from boot screen to terminal.

01

Wayland first

Modern compositing, smooth motion, and desktop targets designed for today's Linux graphics stack.

02

One visual language

Emerald glass, black space, crystalline geometry, subtle glow, and motion that stays restrained.

03

Practical tooling

Kitty, Zsh, Fastfetch, Fuzzel, Yazi, PipeWire, Matugen, and the rest of the Aurora workflow.

04

Open by default

Configs, artwork, installers, and desktop work remain visible and remixable in the project repo.
