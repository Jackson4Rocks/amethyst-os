WHY CALYPSO

Quietly ambitious.

Calypso is not trying to stack every tool on top of every other tool. The goal is a cohesive desktop that feels intentional the moment you boot it.

01 / DESKTOP

KDE, refined.

KDE Plasma is the center of the experience, with Calypso's own visual identity and sensible defaults around it.

02 / INSTALL

Graphical from the start.

Calamares gives Calypso a proper desktop installer instead of relying on a fragile terminal-driven installation script.

03 / IDENTITY

One language.

Crystalline emerald artwork, dark surfaces, subtle glow, and a consistent mark travel from the ISO into the desktop.

04 / FREEDOM

Make it yours.

The project stays open so you can inspect it, modify it, rebuild it, and help shape where it goes next.

THE DESKTOP

A calmer way to Linux.

KDE Plasma is the primary desktop. An optional window manager is also available for users who want a more keyboard-driven, highly customizable workflow.

MAIN DESKTOP

KDE Plasma

A full desktop environment with panels, applications, settings, accessibility, and the flexibility Linux users expect — presented through Calypso's emerald-and-black identity.

Default experience
Optional window manager Recommended for users who prefer a compact, keyboard-driven workflow with deeper customization.

Crystalline design

Dark glass, emerald highlights, geometric forms, and restrained motion turn the whole system into one visual object.

Useful by default

Every choice is there for a reason: everyday applications, coherent branding, practical services, and a clean starting point.

INSTALL CALYPSO

A proper graphical install.

Calypso now uses Calamares for installation, giving the project a polished GUI flow for disk setup, user creation, system configuration, and bootloader installation.
