01 · INSTALLATION

Install Calypso Linux.

The current native installer performs a guided UEFI whole-disk installation. It asks for the target disk, username, hostname, timezone, and desktop profile.

01

Boot the Calypso ISO in UEFI mode.

Connect to the network from the live environment before starting the installer.

02

Launch the installer.

Run calypso-installer or use the live desktop installer entry.

03

Choose your desktop.

Pick Hyprland, GNOME, KDE Plasma, or Niri. Aurora Dotfiles are currently applied only to the Hyprland profile.

04

Confirm the disk wipe.

The current installer is whole-disk only. It does not currently provide a dual-boot partitioning flow.

Important: the selected target disk is erased. Verify the disk carefully before confirming the WIPE /dev/... prompt.

03 · AURORA DOTFILES

Hyprland, tuned by hand.

Aurora currently contains the Hyprland desktop profile, with Quickshell as the shell layer and Matugen driving wallpaper-derived colors.

◈

Hyprland

Lua-based Hyprland configuration, keybinds, workspace behavior, and window rules.

◇

Quickshell

The Aurora shell lives in ~/.config/quickshell/aurora and provides the desktop UI.

⌁

Dynamic theme

Matugen generates the Quickshell, Kitty, and Fuzzel color layers from the wallpaper.

✦

Wallpaper workflow

calypso-wallpaper changes the wallpaper and refreshes the generated theme assets.

cd dotfiles
bash scripts/install.sh

# Reload the Hyprland session
hyprctl reload
04 · BUILD THE ISO

From repository to ISO.

Calypso uses mkarchiso with the profile under iso/. Build artifacts are intentionally kept out of Git.

cd ~/calypso-linux

# Clean stale build state only when no mounts are active
findmnt -R "$PWD/work-build"

# Build
mkarchiso -v -r \
  -w "$HOME/calypso-linux/work-build" \
  -o "$HOME/calypso-linux/out" \
  iso
Tip: if the build complains about mounted work directories, clean the mounts first instead of deleting a mounted path.
05 · DEVELOPMENT

Keep the project coherent.

The repository separates the ISO profile, Aurora Dotfiles, branding assets, and website. Changes to one layer should keep the same Calypso identity.

01

iso/

Live ISO profile, packages, boot configuration, installer, skeleton files, and system defaults.

02

dotfiles/

Aurora Dotfiles and supporting user configuration for the current Hyprland target.

03

assets/

Canonical Calypso visual assets. The original PNG mark is used as the primary visible logo.

04

Website

Static GitHub Pages site with SEO metadata, sitemap support, documentation, and project navigation.
