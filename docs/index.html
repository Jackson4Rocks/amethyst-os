CALYPSO LINUX · CURRENT DOCUMENTATION

Build. Install.
Make it yours.

Calypso Linux is an Arch-based distribution centered on KDE Plasma. Hyprland is included as an optional, recommended window manager for users who want a tiling, keyboard-driven workflow.

InstallationBuild the ISO
01 · INSTALLATION

Calamares, not a terminal maze.

The live ISO uses Calamares for the graphical installation flow. The current setup provides GPT by default, ext4 as the default filesystem, SDDM for login, KDE Plasma as the main desktop, and systemd-boot on UEFI systems.

01

Boot the ISO in UEFI mode.

Start the live environment and connect to the network if required.

02

Launch Calamares.

Use the desktop installer entry or run calypso-calamares from a terminal.

03

Choose disk and account settings.

Calamares handles partitioning, filesystem selection, locale, keyboard, user creation, and hostname setup.

04

Install and reboot.

The installer configures SDDM, system services, initramfs, and systemd-boot before handing control to the installed system.

Back up first. Disk operations can erase data depending on the partitioning choice you make in Calamares. Read the final summary carefully.
02 · DESKTOP

KDE Plasma is home base.

KDE Plasma is the main Calypso desktop and the primary experience represented by the live ISO. The project layers its own branding, wallpapers, installer, and defaults on top of Plasma.

MAIN DESKTOP

KDE Plasma

Full desktop environment, flexible settings, graphical applications, and the default Calypso presentation.

OPTIONAL WINDOW MANAGER

Hyprland

Optional but recommended for a tiling and keyboard-driven workflow with deeper customization.

03 · OPTIONAL HYPRLAND

Keep the power-user path separate.

The optional Hyprland configuration lives in dotfiles/. It is not required for KDE Plasma and can evolve without forcing the same stack onto the main desktop.

CONFIG

Hyprland

Window rules, keybindings, workspaces, focus behavior, and compositor configuration.

SHELL

Quickshell

The current optional Hyprland profile uses Quickshell for its desktop shell layer.

THEMING

Matugen

Wallpaper-derived colors can feed the optional shell and supporting applications.

TOOLS

Optional stack

The configuration may also use Kitty, Fastfetch, Fuzzel, Yazi, Hyprpaper, and Zsh.

cd dotfiles
bash scripts/install.sh

hyprctl reload
04 · ISO BUILD

Build from the profile.

Calypso is assembled through mkarchiso using the iso/ profile. Keep the working tree and output directory outside the profile so the build remains clean.

cd ~/calypso-linux

git pull --ff-only origin main

sudo rm -rf ~/calypso-build ~/calypso-out
mkdir -p ~/calypso-build ~/calypso-out

sudo mkarchiso -v -r \
  -w ~/calypso-build \
  -o ~/calypso-out \
  ./iso
Build note: keep the work directory out of /tmp when the system uses a small tmpfs. The build can consume several gigabytes of temporary space.
