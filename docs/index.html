Calypso Linux is an Arch-based distribution focused on a clean desktop experience, sensible defaults, and a system that stays quick and purposeful. KDE Plasma is at the center, while users who prefer a more tiling, keyboard-driven workflow can choose the optional Hyprland path.

01 · INSTALLATION

From live image to desktop.

The live ISO provides a graphical installation flow designed to keep setup straightforward. The current system targets UEFI installations, GPT partitioning, ext4 by default, SDDM, and systemd-boot.

01

Boot the live image.

Start Calypso in UEFI mode and connect to the network when required.

02

Open the graphical installer.

Launch the installer from the live desktop and follow the guided setup.

03

Configure storage and your account.

Choose the target disk, filesystem options, locale, keyboard layout, hostname, and user account.

04

Install and reboot.

The installer copies the system, configures services and the boot path, then hands control to the installed desktop.

Back up first. Disk operations can erase data depending on the partitioning choice. Review the final storage summary carefully before continuing.
02 · DESKTOP

Shape the experience around you.

Calypso does not need to force a desktop identity onto you. KDE Plasma provides the main desktop experience, while the project also supports an optional Hyprland path for people who want a different style of interaction.

The choice is yours. The desktop experience is designed to remain cohesive either way.
DESKTOP EXPERIENCE

KDE Plasma

A full-featured desktop with broad configuration options, familiar workflows, graphical applications, and the core Calypso presentation.

OPTIONAL PATH

Hyprland

Available for users who prefer tiling, keyboard-driven interaction, and deeper compositor-level customization. The configuration remains separate from the core desktop.

03 · OPTIONAL HYPRLAND

A separate power-user path.

The optional configuration lives under dotfiles/, allowing it to evolve independently while keeping the main desktop clean and easy to understand.

CORE

Hyprland

Compositor settings, window rules, keybindings, workspaces, focus behavior, and other window-management details.

SHELL

Quickshell

The optional profile uses Quickshell as its shell layer for panels, controls, and surrounding desktop UI.

THEMING

Matugen

Wallpaper-derived colors can feed the optional shell and supporting applications for a more cohesive look.

TOOLS

Supporting utilities

The profile may also use Kitty, Fastfetch, Fuzzel, Yazi, Hyprpaper, and Zsh as part of the optional workflow.

04 · ISO BUILD

Build from the profile.

Calypso is assembled with mkarchiso using the iso/ profile. Keeping working files outside the profile makes repeated builds easier to manage.

cd ~/calypso-linux

git pull --ff-only origin main

sudo rm -rf ~/calypso-build ~/calypso-out
mkdir -p ~/calypso-build ~/calypso-out

sudo mkarchiso -v -r \
  -w ~/calypso-build \
  -o ~/calypso-out \
  ./iso
Build note: keep the work directory out of /tmp when the system uses a small tmpfs. The build can consume several gigabytes of temporary space.
